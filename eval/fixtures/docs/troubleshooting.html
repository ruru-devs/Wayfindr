Resolving HTTP 429 Too Many Requests

If your client exceeds configured request throughput limits, the API returns a 429 status code. Implement exponential backoff with jitter in your network client. Inspect the Retry-After header to determine the required wait duration before retrying.

Code: 429 Too Many Requests

Client Timeout Debugging & AbortController

Search requests should complete under 100 milliseconds. If queries exceed 500ms, check network round-trip latency and ensure in-flight searches use AbortController signal cancellation when the user types subsequent keystrokes.

Code: Request Timeout

Locator Fallback for Pages Missing Anchor IDs

When target web sections lack native HTML id attributes, WarpAPI generates CSS DOM paths and W3C text fragment locators (#:~:text=...) so the browser can accurately highlight the landed paragraph upon arrival.

Fallback: W3C Text Fragments
