POST /api/search — High-Speed Intent Search

Submit natural-language visitor queries to receive ranked matching section nodes within 10 milliseconds. Accepts JSON payload containing site_id, query string, and optional top_k parameter. Returns an array of search results with deep links and anchor IDs.

Method: POST /api/search
View Search Request Schema

POST /api/ingest — Real-Time HTML Ingestion

Ingests raw HTML markup, parses hierarchical DOM nodes, extracts action links, and indexes semantic sections into the site search engine. Supports incremental upserts using SHA-256 content change detection hashing.

Method: POST /api/ingest
View Ingest Request Schema

GET /api/analytics/{site_id} — Findability Telemetry

Retrieves aggregate site search analytics including total query volume, zero-match lost queries, click-through rate (CTR), and visitor satisfaction feedback. Requires owner API key authentication.

Method: GET /api/analytics/{site_id}
