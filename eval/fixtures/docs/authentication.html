HMAC SHA-256 API Key Authentication

All administrative requests must include your secret API key either in the X-API-Key HTTP header or as a Bearer token in the Authorization header. Plaintext API keys are never stored on server disks; only cryptographic SHA-256 hashes are persisted.

Tenant Isolation & Scoped Credentials

Every site_id is cryptographically tied to its owner API key. A credential generated for site A cannot read, query, export, or mutate resources belonging to site B. Unauthorized cross-tenant calls are rejected with HTTP 403 Forbidden.

Status: 403 Forbidden on Mismatch

Rate Limiting & Burst Allowances

Public search APIs permit up to 60 requests per minute per IP address and 600 requests per minute per registered site. When limits are exceeded, the API responds with HTTP 429 Too Many Requests along with a Retry-After response header.

Limit: 60 req/min per IP
