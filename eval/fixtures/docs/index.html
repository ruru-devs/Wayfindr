Quickstart & SDK Installation

WarpAPI provides sub-10ms intent navigation APIs for modern web applications. Install the official client library via npm with npm install @warpapi/client or via Python package index with pip install warpapi-client to initialize the runtime engine.

Architecture & Core Engine Components

The platform consists of a distributed BM25Plus inverted index, local bi-encoder semantic reranker, real-time telemetry pipeline, and SQLite metadata store designed for zero external cloud dependency.
